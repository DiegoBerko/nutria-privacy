Política de Privacidad

Última actualización: 15 de abril de 2025

Esta política de privacidad describe cómo la aplicación Nutria ("la app") maneja la información del usuario.

1. Datos que recopilamos

La app no recopila, transmite ni almacena ningún dato en servidores externos. Toda la información ingresada por el usuario (perfil, registros de comidas, entrenamientos, medidas y configuraciones) se guarda únicamente en el dispositivo local del usuario.

2. Uso de la cámara

La app solicita acceso a la cámara exclusivamente para permitir al usuario fotografiar etiquetas nutricionales de productos. Las imágenes tomadas se procesan localmente o se envían a la API de inteligencia artificial configurada por el propio usuario (Groq o equivalente) y no son almacenadas ni compartidas por Nutria.

3. API keys de terceros

La app puede utilizar servicios de terceros (Groq, Edamam) para funciones de IA y búsqueda de alimentos. Las claves de API son ingresadas y administradas por el propio usuario. Nutria no tiene acceso a dichas claves fuera del dispositivo.

4. Datos de salud y nutrición

Los registros de alimentación, peso, entrenamientos y objetivos nutricionales se almacenan exclusivamente en el almacenamiento local del dispositivo. No se sincronizan con ningún servidor externo ni se comparten con terceros.

5. Permisos utilizados

  • Cámara: para escanear etiquetas nutricionales.
  • Micrófono: para el ingreso de alimentos y notas por voz.
  • Almacenamiento: para exportar e importar copias de seguridad de datos en el dispositivo.
  • Internet: para comunicarse con las APIs de IA configuradas por el usuario.

6. Menores de edad

La app no está dirigida a menores de 13 años y no recopila información de menores de forma intencional.

7. Cambios a esta política

Podemos actualizar esta política ocasionalmente. Los cambios se publicarán en esta misma página con la fecha de actualización correspondiente.
